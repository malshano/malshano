## Hi, I'm Malshan 👋

Hardware Engineer at **ScoutDI**, working on drone systems and hardware design, based in Norway 🇳🇴.
Curiosity drives me: I like to build things and push my own boundaries, from flying wings and electronics to furniture, films and DJ sets.

🌐 **Portfolio:** [malshano.com](https://malshano.com) · 💼 [LinkedIn](https://www.linkedin.com/in/malshan-perera/)

### 🧭 What I do

- **Hardware and drone systems:** electronics, PCB design and system integration
- **Embedded firmware:** ESP32, Arduino and Raspberry Pi
- **Engineering simulation:** CFD and FEM analysis
- **AI agents and automation:** practical tools built with LLMs
- **Data analysis:** scraping, visualisation and tooling
- **Building things:** woodworking, motorcycles, robots and gadgets

### 🛠️ Public projects

- [ESP Bed Presence](https://github.com/malshano/ESPBed_presense): bed occupancy sensing on an ESP32 with Home Assistant
- [WeatherPump](https://github.com/malshano/WeatherPump): a weather-driven pump controller, built for Oslo kommune under Project Hydra
- [SunTrigger](https://github.com/malshano/SunTrigger): a sunrise alarm clock with a custom PCB
- [Finn-search](https://github.com/malshano/Finn-search): housing market analysis and charts in Python
- [malshano.github.io](https://github.com/malshano/malshano.github.io): my portfolio site

More on the [portfolio site](https://malshano.com): a flying wing UAV with ANSYS CFD, a bartender robot, a breathalyser, a CB750 rebuild and a surfboard coffee table.
